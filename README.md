# Basket Cholet — V3 (17 octobre 2026)

Site statique pour GitHub Pages. 29 fiches examinées dont 16 repères cartographiés. Les repères géolocalisent souvent une installation sportive, **pas le panier exact**.

Mise à jour : 4 nouvelles fiches (Trémentines ×2, Montfaucon-Montigné, Bostangis) ; rapprochement du plateau Roland-Geneste avec le secteur Turbaudières pour éviter un doublon ; sources/limitations ajoutées dans les fiches ; aucun visuel générique présenté comme une photographie.

**Important** : « Accès public signalé » n'est pas une garantie d'accès libre permanent. Les fiches scolaires sont séparées. La présence du panier n'est pas confirmée sur certains sites. Aucune vérification physique effectuée. Le site utilise Leaflet et OpenStreetMap via Internet.

Déployer les fichiers à la racine de la branche GitHub Pages, en remplaçant `index.html` et `terrains_basket_cholet.geojson`. Ne pas importer le ZIP comme fichier unique.
